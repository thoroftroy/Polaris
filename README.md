# Polaris

The Wonderdesk web browser for Android: Wonderdesk look, private Veil tabs by default, ad and tracker blocking, desktop site and browser disguise, per-site open-in-app rules, bookmarks and history, find in page, reader view, add sites to the home screen.

Built on Android System WebView with the Wonderdesk kit. Passwords fill through Wonderdesk Vault (Android autofill).
